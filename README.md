# AIR-MOUSE-WATCH

A free Apple Watch motion-controlled mouse for Windows.

## Project goal

Turn an Apple Watch into a wireless air mouse using its motion sensors.

## Hardware

- Apple Watch Series 12
- iPhone 15
- Windows 11 PC

## Features planned

- Motion-controlled cursor
- Left and right click
- Scrolling
- Adjustable sensitivity

## Privacy

Designed to work over a trusted local network.
